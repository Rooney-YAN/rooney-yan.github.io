## 关于这个项目

这个仓库用于维护我的个人网站。

它是我公开展示项目、研究方向、技术实践与长期写作的统一入口。相比把网站做成一份静态简历，我更希望它成为一个会持续生长的个人工作索引。

## 网站内容

- **Projects** — 软件项目、实验与原型
- **Research** — 当前研究兴趣、研究工作与阅读方向
- **Writing** — 技术笔记、思考与长文
- **About** — 个人背景、兴趣方向与联系方式

## 技术栈

| 层级 | 技术 |
| --- | --- |
| UI | React |
| 构建工具 | Vite |
| 语言 | TypeScript / JavaScript |
| 部署 | GitHub Pages |
| 包管理器 | pnpm |

整个网站采用静态前端架构，使用 Vite 构建，并通过 GitHub Pages 部署。

## 本地开发

```bash
git clone https://github.com/Rooney-YAN/rooney-yan.github.io.git
cd rooney-yan.github.io

pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

本地预览：

```bash
pnpm preview
```

## 设计方向

这个网站遵循一个很简单的原则：

> **用一个地方持续记录我构建、学习与公开表达的东西。**

它不是一个一次性完成的作品，而是一个会随着项目、研究和写作不断更新的长期页面。
